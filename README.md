# Sprites Quasi-Electrostatic Model
Building a quasi electrostatic model of red sprites, making multiple tiers of complexity with the end goal being to have created serious hypothesis on the mysteries regarding red sprites.

## Current Goal
Build a basic 2D quasi electrostatic model that can calculate the electric field above a simplified thundercloud charge and checks for conditions that cause and initiate sprites.

## Long-term Direction
Gradually adding more realistic elements and multiple layers, time evolution, and visualization, moving toward a more complex model as my understanding and skills improve.

## Approach
- Start with the simplest working version
- Document every major step and pivots in complexity
- Only increase complexity when the current version is understood and working
